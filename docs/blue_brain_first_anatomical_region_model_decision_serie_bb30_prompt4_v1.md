## 1) Region under decision

The selected first anatomical region remains:

- `hippocampus_like_region`

Its operational role remains context/reference-heavy advisory shaping for runtime/selection/reference handoff quality, not action authority.

The canonical map for this region is:

## 3) Current-mode decision (now)

For `hippocampus_like_region`, the canonical **current mode now** is:

- `abstract functional current mode`

Reasoning:

- The present UCF leverage is in bounded context/reference modulation quality, not membrane/spiking fidelity.
- Existing BB17/BB19/BB21/BB24–BB29 contracts already provide bounded advisory/reference surfaces with no direct authority.
- Abstract functional modeling preserves determinism and scope control while fitting the first anatomical integration from BB30 Prompt 3.

## 4) Kuramoto-vs-abstract-vs-HH boundary for this region

### 4.1 abstract functional (chosen now)

- Not a second-class fallback; it is the correct early systems layer for this region.
- Gives enough structure for advisory context/reference shaping without adding dynamics-heavy risk.
- Keeps no direct action execution and no retry orchestration.

### 4.2 bounded Kuramoto-like (viable only if later needed)

- Kuramoto is only suitable if bounded coupling/synchrony/gating/timing modulation for this region shows concrete additional UCF value.
- Must remain advisory-only/bounded (hint/caveat/diagnostic lane), never direct execution control.
- Not default for every anatomical region and not promoted as default here.

### 4.3 Hodgkin-Huxley (not current mode)

- HH stays significantly heavier and therefore only meaningful as simulation/diagnostic or later selective deepening.
- For this first anatomical region, there is currently no strong evidence that excitability/spiking/membrane-near modeling would improve UCF system outcomes enough to justify runtime complexity.
- no HH production integration.

## 5) Explicit now/later/deferred split

- **Now (canonical):** `abstract functional current mode`.
- **Later option (conditional):** `bounded Kuramoto-like current mode` if bounded synchrony/gating utility is empirically shown.
- **Later selective option (conditional):** `later selective HH deepening` only after evidence-backed scope decision.
- **Not leading now:** `Hodgkin-Huxley simulation-only/diagnostic-only current mode`.
- **Explicitly not suitable now:** `deferred/not-suitable-now model path` for over-scoped dynamics attempts.
- **Always non-operational:** `non-canonical/internal-only model path`.
