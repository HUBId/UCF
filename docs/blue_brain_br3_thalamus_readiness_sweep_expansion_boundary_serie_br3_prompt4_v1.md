## 2) Thalamus expansion line

`thalamus_like_region` is now the third real anatomical region, with exactly these canonical surfaces:

1. `thalamus input surface`
2. `thalamus state surface`
3. `thalamus output/advisory surface`
4. `thalamus reference surface`
5. `thalamus diagnostics states`
6. `thalamus contract signals`
7. `stable current model mode`
8. `non-canonical/internal-only thalamus path` as a visible but non-operative class

Canonical interpretation:

- **Input:** only bounded relay/gating/routing/deferral/context/reference/reference-validity basis.
- **State:** only advisory-only, caveated, deferred, blocked, insufficient, diagnostic-only, reference-only, or non-canonical/internal-only status classes.
- **Output:** only advisory relay/routing/gating/caveat/reference-bounded hints and diagnostic outputs.
- **Reference:** read-only/reference-bounded context; no memory mutation or reference-authority escalation.
- **Diagnostics:** diagnostic classes are canonical status reads, not action requests.
- **Contracts:** contract signal is canonical only as a bounded no-direct read.
- **Model:** `abstract functional current mode` is canonical; Kuramoto-like and HH paths are not productive modes.

## 3) Canonical status separation

The following distinctions are hard BR3 boundaries:

- `thalamus input surface` is not `thalamus state surface`.
- `thalamus state surface` is not `thalamus output/advisory surface`.
- `thalamus reference surface` is not a memory-commit surface.
- `thalamus diagnostics states` are not `thalamus contract signals`.
- `thalamus bounded contract signal` is not an execution, retry, compute, or safety channel.
- `thalamus advisory-only diagnostic != thalamus caveated diagnostic`.
- `thalamus caveated diagnostic != thalamus deferred diagnostic`.
- `thalamus deferred diagnostic != thalamus blocked diagnostic`.
- `thalamus blocked diagnostic != thalamus insufficient diagnostic`.
- `thalamus diagnostic-only state != thalamus reference surface`.
- `reference-only` remains read-only and non-actionable.
- `non-canonical/internal-only thalamus path` remains non-operative even when observable.

## 8) Next anatomical region decision handoff: Basal Ganglia before Cerebellum in BR4

BR3 itself still opens no fourth anatomical region. The earlier BR3-local caution around Basal Ganglia is now explicitly resolved by BR4 Prompt 1 as a narrow, no-direct, abstract-functional role decision.

Decision handoff: **prioritize Basal Ganglia as the next single anatomical-region candidate; keep Cerebellum deferred.**

Repo-side reason for the BR4 handoff:

1. **Direct attachment to existing Selection/Action-gating substance:** Basal Ganglia maps to action-gating mediation, suppression/inhibition hints, bounded selection-channel arbitration, and execution-readiness modulation already present as guarded contract semantics.
2. **Authority risk is contained by BR4 boundaries:** no direct action selection, no direct execution trigger, no retry trigger, no safety override, no policy/governance platform, and no compute-core work remain hard limits.
3. **Cerebellum remains deferred:** Cerebellum can still be evaluated later as diagnostic/advisory calibration or timing support, but it is not the next active BR4 region.
4. **No concurrent rollout:** the handoff authorizes only the Basal-Ganglia role-definition line in BR4, not a broad platform or parallel Cerebellum implementation.
5. **Why HH-heavy regions wait:** HH-heavy or production-biophysics candidates would increase model-platform and compute-core pressure before the abstract functional anatomical baseline is stable enough.

This handoff is a single-direction prioritization only. It does not retroactively open a fourth region inside BR3; it points BR4 to the controlled Basal-Ganglia role map.
