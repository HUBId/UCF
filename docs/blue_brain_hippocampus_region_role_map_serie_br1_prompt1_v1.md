# Serie BR1 Prompt 1: Hippocampus-first canonical region role map

Status: Hippocampus is the first real anatomical UCF region with a bounded functional integration mode over existing BlueBrain lines.

## 1) canonical Hippocampus system role in UCF

Hippocampus is explicitly pinned as the **context-memory-reference binding region** for the current UCF anatomical stage.

Its canonical role is bounded to:

- context indexing role (runtime-visible context keys and snapshots),
- memory association role (linking transient memory candidates and persisted-reference IDs without granting commit authority),
- episode/reference binding role (tie evidence/replay/reference episodes to a coherent retrieval basis),
- bounded retrieval support role (advisory retrieval cues only, no ranking platform).

This is a functional system role, not a biological full-fidelity hippocampus implementation.

## 2) attachment to existing BlueBrain lines

Hippocampus attaches to already existing lines and does not open a new platform:

- **Context/Memory/Reference**: strengthens context indexing, association, and episode/reference binding semantics.
- **Selection**: bounded influence only through advisory/reference quality signals.
- **Runtime**: bounded informative feedback only (diagnostic/caveat/reference lane), never direct action authority.
- **Contract line**: remains under no-direct-* constraints and reference/diagnostic contract semantics.

Hippocampus has **no direct action/retry/execution/memory/compute authority**.

## 3) current integration mode (explicit)

Current BR1 integration mode is:

- hippocampus: **abstract functional (current/default)**,
- bounded kuramoto-like: candidate lane for selected non-hippocampus region classes,
- HH simulation-only/diagnostic-only: allowed only as non-productive diagnostics lane,
- later selective HH deepening: explicitly deferred and selective,
- deferred components: multi-region expansion and deep biological modeling.

No implicit HH requirement is introduced for Hippocampus in BR1.

## 4) regional boundary vs other anatomical candidates

Hippocampus is differentiated as the first region for context-memory-reference binding.

Other region classes remain non-primary in BR1 scope:

- amygdala: threat/caveat salience lane,
- thalamus: relay/integration lane,
- prefrontal cortex: policy/control consistency lane,
- anterior cingulate cortex: conflict-monitoring lane,
- basal ganglia: action-gating mediation lane,
- insula: interoceptive context lane.

These mappings do not grant those regions direct runtime authority in BR1.

## 5) explicit out-of-scope / deferred

In this step, explicitly out of scope:

- no full biological hippocampus reconstruction,
- no productive HH integration,
- no direct execution/safety/memory authority,
- no new compute-core expansion,
- no planner/agent/retry/orchestration platform,
- no new policy/governance platform,
- no implicit memory persistence broadening.

## 6) implementation next-step anchor (BR1 continuation)

This BR1 role map is the canonical anchor for the next implementation stage:

1. encode hippocampus-specific role tokens in existing contract diagnostics,
2. harden context-memory-reference binding checks for hippocampus lane,
3. add bounded retrieval-support diagnostics without retrieval platform expansion,
4. keep selection/runtime coupling advisory-only with explicit caveat states,
5. add regression checks that reject any direct-authority scope drift.
