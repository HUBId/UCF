# Serie BR2 Prompt 1: Amygdala als nächste echte Hirnregion funktional festziehen

Status: `amygdala_like_region` wird als **nächste echte anatomische Region** nach BR1-Hippocampus funktional festgezogen, strikt bounded und advisory-only.

## 1) Repo-basierte Amygdala-Funktionsfläche (bestehender Anschluss)

Amygdala-nahe Signale sind im aktuellen UCF-Stand bereits indirekt vorhanden über:

- salience-/priority-nahe selection weighting
- caveat/threat/urgency diagnostics
- reference quality caveat/deferred/blocked Semantik
- bounded runtime-selection coupling ohne direkte Autorität

Diese Substanz ist der technische Hebel für BR2; es wird **keine** neue globale Neuroplattform geöffnet.

## 2) Kanonische Amygdala-Rollenkarte

Die kanonische Amygdala-Rolle in BR2 ist auf genau fünf Klassen begrenzt:

1. `salience weighting role`
2. `threat/valence caveat role`
3. `bounded priority modulation role`
4. `reference-linked affective tagging role`
5. `non-role / out-of-scope biological detail`

Interpretation:
- Amygdala ist in UCF eine **advisory salience/valence/caveat Region**, keine Action- oder Governance-Instanz.
- Die Rolle bleibt funktional-systemisch und ist kein biologischer Vollnachbau.

## 3) Current integration mode (BR2)

Aktueller Integrationsmodus für Amygdala ist:

- `abstract functional current mode` (operativ für BR2)

Explizit **nicht** impliziert:

- keine HH-Produktivpflicht
- kein automatischer Wechsel zu `bounded Kuramoto-like` als Produktionsmodus
- HH bleibt `simulation-only/diagnostic-only` bzw. `later selective HH deepening` als gesonderter späterer Re-Scope
- deferred components bleiben deferred

## 4) Spiegelung gegen bestehende BlueBrain-Linien

Amygdala ist an bestehende Linien angebunden, aber strikt begrenzt:

- **Selection/Priority/Caveat:** advisory salience/valence/caveat weighting, keine direkte Promotion-/Freigabeautorität.
- **Reference/Context:** nur bounded affective tagging an bestehende reference validity/caveat/deferred Semantik.
- **Runtime:** runtime liest bounded advisory Signale; keine direkte execution/retry/memory/compute Steuerung.

No-direct-* Grenzen bleiben unverändert:

- no direct action trigger
- no direct execution trigger
- no direct retry trigger
- no direct memory commit
- no direct compute invocation
- no safety override

## 5) Abgrenzung: Hippocampus vs Amygdala

Klare Rollentrennung in BR2:

- `hippocampus_like_region`: context/reference/episode/indexing-lastig
- `amygdala_like_region`: salience/valence/caveat/priority-lastig

Damit entsteht keine semantische Dublette:

- Hippocampus liefert bounded context-memory-reference shaping.
- Amygdala liefert bounded salience/valence caveat modulation.
- Beide dürfen später komplementär zusammenwirken, bleiben aber **nicht austauschbar**.

## 6) Explizit out-of-scope in diesem Schritt

- kein vollständiger biologischer Amygdala-Nachbau
- keine HH-Produktivintegration
- keine direkte Execution-/Safety-/Memory-Autorität
- keine Planner-/Agenten-/Governance-/Retry-/Orchestration-Plattform
- keine neue Compute-Core-Arbeit
- keine globale Neurodynamikplattform

## 7) Nächste BR2-Folgearbeiten (gezielt, 3–5 Schritte)

1. Amygdala-spezifische contract/diagnostic token fixtures für salience/caveat/valence in bestehende tests aufnehmen.
2. Runtime/Selection snapshots um amygdala advisory markers regressionssicher machen (ohne Autoritätserweiterung).
3. Reference-linked affective tagging auf caveated/deferred/blocked Übergänge explizit testen.
4. Guard-Prüfungen ergänzen, damit `hippocampus_like_region` und `amygdala_like_region` nicht semantisch zusammenfallen.
5. Erst danach optionalen Re-Scope für bounded Kuramoto-like Amygdala-Kopplung separat entscheiden.
