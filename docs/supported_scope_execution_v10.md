# Supported Scope Execution v10 (Historical)

v10 introduced `SupportedScopeExecutionV5` as the then-authoritative execution artifact bound to canonical governance + final governance-consumer authority.

## Superseded by v11

In v11, execution authority moves to `SupportedScopeExecutionV6`, which additionally requires `FinalGovernanceResidualSweepV1` PASS before one-slot expansion may execute.

Use:

- `docs/supported_scope_execution_v11.md` for current execution flow.
- `docs/supported_set_apply_v6.md` for apply semantics under v11.
