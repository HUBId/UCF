# Serie BR3 Prompt 1: Thalamus als nächste echte Hirnregion funktional festziehen

Status: `thalamus_like_region` wird nach BR1 (Hippocampus) und BR2 (Amygdala) als **nächste echte anatomische Region** für UCF funktional festgezogen, strikt bounded und advisory-only.

## 1) Repo-basierte Thalamus-Funktionsfläche (bestehender Anschluss)

Thalamus-nahe Funktionalität ist im aktuellen Repo bereits als bounded Substanz vorhanden über:

- relay-/gating-nahe runtime-facing Signalschichten (runtime↔selection advisory mediation)
- bounded routing/deferral/caveat contract Semantik
- reference/context-vermittelte Signalweitergabe ohne direkte Autorität
- bestehende `RelayIntegrationMediation`-Rollenlinie im anatomischen Regionsmapping

Das ist die technische Anschlussfläche für BR3; es wird **keine** neue globale Neurodynamik-, Agenten- oder Orchestrierungsplattform geöffnet.

## 2) Kanonische Thalamus-Rollenkarte

Die kanonische Thalamus-Rolle in BR3 ist auf genau fünf Klassen begrenzt:

1. `relay/gating role`
2. `bounded routing role`
3. `selection-support role`
4. `reference-mediated signal routing role`
5. `non-role / out-of-scope biological detail`

Interpretation:

- Thalamus ist in UCF eine **advisory relay/gating/routing Region**.
- Keine direkte Action-, Retry-, Memory-, Safety- oder Compute-Autorität.
- Keine semantische Gleichsetzung mit Hippocampus, Amygdala oder Basal Ganglia.

## 3) Current integration mode (BR3)

Aktueller Integrationsmodus für Thalamus ist:

- `abstract functional current mode` (operativ in BR3)

Explizit weiterhin unterschieden:

- `bounded Kuramoto-like candidate` bleibt optionaler späterer Kandidat nur bei belastbarer Zusatzwirkung.
- `Hodgkin-Huxley simulation-only/diagnostic-only` bleibt nicht-operativ.
- `later selective HH deepening` bleibt separater späterer Re-Scope.
- deferred components bleiben deferred.

Damit wird **keine implizite HH-Pflicht** und **kein impliziter Kuramoto-Produktivzwang** erzeugt.

## 4) Spiegelung gegen bestehende BlueBrain-Linien

Thalamus stützt bestehende Linien klar begrenzt:

- **Runtime/Selection/Routing:** relay/gating/routing advisory shaping innerhalb bestehender guard rails.
- **Reference/Context:** nur bounded reference-mediated routing influence, kein Authority-Eskalationspfad.
- **Diagnostics/Contracts:** caveated/deferred/blocked/insufficient Zustände bleiben contract-lesbar, nicht ausführungswirksam.

No-direct-* Grenzen bleiben unverändert:

- no direct action trigger
- no direct execution trigger
- no direct retry trigger
- no direct memory commit
- no direct compute invocation
- no safety override

## 5) Abgrenzung: Hippocampus vs Amygdala vs Thalamus

Klare Rollentrennung in BR3:

- `hippocampus_like_region`: context/reference/episode/indexing-lastig
- `amygdala_like_region`: salience/valence/caveat/priority-lastig
- `thalamus_like_region`: relay/gating/routing-lastig

Konsequenz:

- keine semantische Dublette.
- spätere bounded Kopplung bleibt komplementär und bedeutet **keine** Gleichsetzung.

## 6) Explizit out-of-scope in diesem Schritt

- kein vollständiger biologischer Thalamus-Nachbau
- keine HH-Produktivintegration
