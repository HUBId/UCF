## 2) Basal-Ganglia expansion line

`basal_ganglia_like_region` is now the fourth real anatomical brain region, with exactly these canonical surfaces:

1. `basal-ganglia input surface`
2. `basal-ganglia state surface`
3. `basal-ganglia output/advisory surface`
4. `basal-ganglia reference surface`
5. `basal-ganglia diagnostics states`
6. `basal-ganglia contract signals`
7. `stable current model mode`
8. `non-canonical/internal-only basal-ganglia path` as a visible but non-operative class

Canonical interpretation:

- **Input:** only bounded runtime-readiness, selection-priority, selection-deferral, action-gating-posture, context-reference, and reference-validity basis.
- **State:** only advisory-only, caveated, deferred, blocked, insufficient, diagnostic-only, reference-only, or non-canonical/internal-only status classes.
- **Output:** only advisory gating/suppression/channel-selection/caveat/reference-bounded hints and diagnostic outputs.
- **Reference:** read-only/reference-bounded context; no memory mutation, persistence, retrieval expansion, or reference-authority escalation.
- **Diagnostics:** diagnostic classes are canonical status reads, not action requests.
- **Contracts:** contract signal is canonical only as a bounded no-direct read.
- **Model:** `abstract functional current mode` is canonical; Kuramoto-like and HH paths are not productive modes.

## 8) Next anatomical region decision: Cerebellum before Hypothalamus

Decision handoff: **prioritize Cerebellum as the next single anatomical-region candidate; keep Hypothalamus deferred.**

Repo-based reason:

1. **Higher near-term technical leverage:** after Basal-Ganglia action-gating hints, Cerebellum maps more cleanly to bounded calibration/timing/error-correction diagnostics without needing authority over setpoints, survival drives, policy, memory, or safety.
2. **Cleaner attachment to existing UCF basis:** Cerebellum can attach as advisory calibration/timing support to existing Runtime/Selection/Execution-reference reads, while preserving no-direct execution and no retry orchestration.
3. **Lower scope risk than Hypothalamus:** Hypothalamus tends toward setpoint, drive, homeostasis, autonomic control, and safety-like interpretations; those are more likely to blur into policy/governance, safety override, or control authority and should wait.
4. **HH-heavy regions still wait:** HH-heavy or deeper biophysical regions require explicit simulation-only or later-deepening decisions and are not justified by this BR4 closeout.
5. **No concurrent rollout:** the handoff authorizes only a later Cerebellum role-definition decision, not an implementation here and not parallel Cerebellum/Hypothalamus expansion.

This handoff does not open a fifth region inside BR4. It only identifies the next candidate for a future controlled anatomical-region prompt.
