# Roadmap Anchor — Real Compute Onboarding v7

## Scope guardrails

v7 remains:

- hardware-neutral
- offline-first
- probe-first
- shadow-first
- fail-closed

No v7 item may widen runtime semantics without explicit supported-set policy, applied-set authority, and evidence scaffolding alignment.

## MUST (v7)

1. Deepen applied-scope governance reuse across all active review/export/gate surfaces.
2. Harden evidence/export/signoff interoperability further without widening runtime semantics.
3. Consider supported-scope expansion only where applied policy and evidence scaffolding explicitly justify it.
4. Keep the Active path conservative and explicitly evidence-bound.

## NICE (v7)

1. Add bounded automation for review/export chains.
2. Increase schema/report/export normalization where it reduces operator ambiguity.
3. Improve operator docs/runbook ergonomics for the governed applied scope.

## DEFERRED (v7)

- Training flows.
- Remote compute assumptions.
- GPU-required flows.
- Hardware-specific optimization assumptions.
- Broad scope expansion without evidence scaffolding.
