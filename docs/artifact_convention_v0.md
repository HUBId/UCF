# v0 Artifact Directory Convention

All sign-off outputs are stored under:

- `./out/<run_id>/`

Expected files:
- `run_metadata.json`
- `gate_report.json`
- `adversarial_report.json`
- `bench_report.json`
- `probe_report.json` *(optional when probe is skipped)*
- `replay_report.json`
- `explain_tick_last.json`
- `manifest.json` (generated by `ucf-ops out manifest --dir ./out/<run_id>`)

`manifest.json` is machine-readable and contains every file plus `sha256` and `size_bytes` for reproducibility and tag audits.
