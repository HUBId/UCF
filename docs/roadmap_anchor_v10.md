# Roadmap Anchor v10

v10 starts after v9 gate PASS and keeps progression conservative, hardware-neutral, and offline-first.

## MUST (v10)
- Deepen final-authority reuse across all active governance/review/export/gate surfaces.
- Harden supported-scope execution continuity and downstream applied-scope consumption without widening runtime semantics.
- Strengthen end-to-end continuity and verification reuse from governance entry to built bundle.
- Keep the Active path conservative, probe-first, shadow-first, fail-closed, and explicitly evidence-bound.

## NICE (v10)
- Richer bounded workflow/export ergonomics.
- Further schema/report/export normalization.
- Improved operator documentation and runbook clarity.

## DEFERRED (v10)
- Training.
- Remote compute.
- GPU-required flows.
- Hardware-specific optimization assumptions.
- Broad scope expansion without final governance authority, current scope execution support, and evidence scaffolding.
